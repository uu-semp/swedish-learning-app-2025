Create a completely new desktop-first interactive prototype for a beginner Swedish learning game called:

“Ett år i Uppsala”

This is the second design iteration of a university course project, but treat this Figma Make page as a completely fresh start.

Do not reuse any previous layouts or clock-based game concepts.

CONTEXT

The game is designed for international students taking “Basic Swedish 1” at Uppsala University.

The purpose is to help complete beginners practise:

- weekdays
- months
- dates and ordinal numbers
- seasons
- basic Swedish weather phrases

The game should feel like one coherent calendar-based learning experience rather than four completely separate mini-games.

The overall concept is:

“Move through one year in Uppsala while completing different Swedish language challenges.”

The player gradually moves through the year and encounters different tasks related to weekdays, months, dates, seasons and weather.

Do NOT include a clock or exercises about telling the time.

DESIGN DIRECTION

Create a modern, friendly educational interface.

The primary design should be desktop-first and approximately 1440 × 900 px.

The game is for university students, so it should:

- feel playful and engaging
- feel modern
- not look childish
- use generous spacing
- use large readable typography
- use rounded cards and buttons
- have a clear visual hierarchy
- use subtle animations and hover states where suitable

Use a light neutral base background.

Use four seasonal accent colours throughout the game:

Winter:
muted blue

Spring:
fresh green

Summer:
warm yellow

Autumn:
burnt orange

USER EXPERIENCE REQUIREMENTS

Keep instructions short.

Avoid long paragraphs during gameplay.

The current question should always be the visual focus.

Use large clickable areas.

Use clear buttons.

Keep navigation consistent.

Include:

back button
home button
next button when appropriate

Use the same visual feedback system throughout the game.

Avoid overwhelming beginners with too much text.

The interface should be understandable even for someone with very limited Swedish.

Use Swedish for the game content.

The overall interface can rely heavily on visual hierarchy and icons so that English explanations are not necessary.

IMPORTANT DESIGN PRINCIPLES

The prototype should feel like ONE game with several interaction types.

Do not make it feel like four unrelated mini-games.

The main metaphor is:

one year in Uppsala.

Weekdays should mainly be practised through:
- weekly schedules
- ordering
- before/after relationships

Months should mainly be practised through:
- chronological ordering
- before/after relationships
- calendar interaction

Dates should mainly be practised through:
- ordinal numbers
- selecting dates in a calendar

Seasons should mainly be practised visually.

Weather should mainly be practised through visual scenes and simple Swedish weather phrases.

Do not use a clock.

Do not create exercises about telling the time.

Do not use real photographs yet.

Use coloured placeholders where future Uppsala photographs will go.

Keep the prototype desktop-friendly.

Keep the design suitable for university students.

Keep all Swedish language content at Basic Swedish 1 level.

Prioritise clarity, variation and visual learning.
