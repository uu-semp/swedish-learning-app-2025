--------------------------------------------------
HOVER TRANSLATIONS / LANGUAGE SUPPORT
--------------------------------------------------

Add an optional English translation tooltip for important Swedish vocabulary throughout the game.

When the user hovers over a Swedish learning word, show a small tooltip with the English translation.

Examples:

måndag → Monday
tisdag → Tuesday
onsdag → Wednesday
torsdag → Thursday
fredag → Friday
lördag → Saturday
söndag → Sunday

januari → January
februari → February
mars → March
april → April
maj → May
juni → June
juli → July
augusti → August
september → September
oktober → October
november → November
december → December

vår → spring
sommar → summer
höst → autumn
vinter → winter

dag → day
vecka → week
månad → month
årstid → season
datum → date

före → before
efter → after

regnar → raining / rains
snöar → snowing / snows
blåser → windy / the wind is blowing
soligt → sunny
molnigt → cloudy
mulet → overcast
varmt → warm
kallt → cold

The tooltip should:
- appear on hover
- be small and unobtrusive
- appear close to the hovered word
- disappear when the pointer leaves
- use the existing visual design system
- have sufficient contrast
- not cover important game content

Make hoverable vocabulary visually discoverable using a very subtle dotted underline or another small indication.

Do not permanently display English translations on the page.

The main interface and exercises should remain in Swedish.

Use English only as optional support.

IMPORTANT:
Do not make every word in every sentence hoverable.

Prioritise vocabulary that the student is expected to learn, especially:
- weekdays
- months
- seasons
- weather vocabulary
- calendar vocabulary
- important instruction words such as “före” and “efter”

For accessibility, the same translation tooltip should also appear when a vocabulary item receives keyboard focus.

If the interface is later adapted for touch devices, allow tapping the vocabulary word to show the same translation.
